📡 ISS Detector 🌍

Track the International Space Station and Get Notified When It’s Near Your Location!



📜 About the Project

ISS Detector is an API-based program that tracks the real-time location of the International Space Station (ISS). It automatically notifies users via email when the ISS is passing near their location.

✨ Features

✔️ Fetches real-time ISS location using APIs

✔️ Determines if the ISS is visible from your location

✔️ Sends email alerts when the ISS is nearby

✔️ Simple and lightweight script


🛠️ Technologies Used

Python 🐍

Requests (for API calls)

SMTP (for email notifications)

JSON (for handling location data)

📦 Installation & Setup

1️⃣ Clone the repository:

git clone https://github.com/Jalaj2002/ISS-Detector.git

cd iss-detector




Run the script:

python iss_detector.py

🌍 How It Works

Fetches the ISS location from an API

Compares it with your geolocation

Sends an email alert if the ISS is passing nearby
